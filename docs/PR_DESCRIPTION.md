## 변경 결과

기존 시작 화면을 브라우저에서 한 판을 끝내고 다시 시작할 수 있는 한국어 싱글플레이 4X 게임으로 확장합니다. 시드 기반 24×18 육각 지도에서 도시·경제·12개 기술·7종 유닛·8종 건물·외교·전투·정복/과학/점수 승리를 운영하며, AI 3세력도 같은 합법 명령 엔진을 사용합니다.

Canvas 지도와 React 패널을 분리하고 IndexedDB 자동 저장/3슬롯/JSON 가져오기 및 복구 검증을 추가했습니다. 모바일 터치, 키보드 조작, 실제 행동을 안내하는 튜토리얼과 결과 화면을 제공합니다. 기존 시작점과 Git 이력을 보존했으며 주요 수치는 `balance.ts`에 모았습니다.

## 검증

- TypeScript strict, ESLint, production build 통과.
- 엔진·저장 규칙 147개 테스트 및 결정론적 지도 50개 검증 통과. 측정한 엔진·저장 분기 커버리지 86.17%.
- 고정 시드 AI 대전 20/20 정상 종료: 37~40라운드, 실제 공격 352회, 점령 9회, 처치 95회. 전부 과학 승리여서 승리 경로 다양성은 추가 밸런스 과제입니다.
- 로컬 운영 빌드를 `/civilization-clone/`에서 HTTP/에셋/새 게임/도시 건설/저장 후 새로고침 검증.
- 최신 로컬 Chrome에서 데스크톱/390px/회전/터치를 포함한 12개 브라우저 시나리오와 두 손가락 핀치 추가 검사 1개 통과. 첫 체크포인트의 원격 CI에서도 Chromium 및 WebKit 15개 시나리오 통과. 실제 수치와 커밋별 증거는 `TEST_REPORT.md`, `artifacts/` 및 PR Checks에 기록합니다. 실제 모바일 기기 검증은 수행하지 않았습니다.
