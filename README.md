# 문명클론 개발 프로젝트

독자적인 턴 기반 문명 전략 웹게임의 사전 작업 저장소. 현재는 실행 가능한 시작 화면이며 게임은 미구현이다.

## 시작
Codespaces에서 저장소를 열고 `npm ci`, `npm run dev`를 실행한다. 5173 포트를 비공개 미리보기로 연다.
검증: `npm run check && npm run build`. 결과는 dist/.

## Codex 개발 요청
AGENTS.md를 읽고 codex/game-mvp 브랜치에서 시드 지도, 정착·도시, 자원·연구, 턴 진행, 저장·이어하기, 승리·패배까지 가능한 MVP를 구현하라. 실제 엔진 테스트와 모바일 UI 검증 후 커밋·push·PR을 남겨라. 공개 배포는 별도 요청 시 docs/DEPLOYMENT.md 절차로 수행하라.
